# 短剧海外发行管理平台 PRD（v1.0，按 2026-10-21 业务口径修订）

> 口径来源：2026-10-21 业务方最新确认，覆盖此前全部假设。
> 文中【待确认】项需业务方拍板后再进开发；其余可直接进入原型/技术方案。

---

## 0. 一句话定位与边界

**定位**：服务短剧版权方（客户）的海外发行"申请—审核—分成—数据—结算"一站式管理平台。

**做什么（范围内）**
1. 发行前内容管理：影片/剧集上传、素材与版权文件管理、发行计划申请。
2. 申请流转：剧集审核、分成配置、工单回传、修改重提、平台定级与选平台。
3. 数据同步展示：各海外平台播放量/收益等表现数据的接口同步或人工同步，并在客户端展示。
4. 结算与提款：按结算周期发起结算、企业认证、发票上传、提款。
5. 防伪留证：带时间戳防伪水印截图，以工单形式供客户查看。

**不做什么（范围外）**
- ❌ 不负责向海外平台推送/分发内容（上架动作由运营+商务线下或在各平台后台完成，本平台只记录结果）。
- ❌ 不做视频转码/字幕翻译生产（只存储与管理成品素材）。
- ❌ 不做与海外平台之间的资金清算（只管理我方与客户之间的结算）。

## 1. 角色与权限

### 1.1 角色定义

| 端 | 角色 | 职责 |
|---|---|---|
| 用户端 | **客户主账号**（企业管理员） | 注册、企业绑定/认证、收款账户、上传影片、发起发行计划、合同申请、看数据、结算提款、管理子账号 |
| 用户端 | **客户子账号**（可选，后续版本） | 由主账号分配：内容上传员 / 数据查看员 / 财务（结算提款） |
| 运营端 | **运营专员** | 审核剧集、配置分成、出审核工单、每日数据同步（手工录入/导入）、出防伪截图工单 |
| 运营端 | **运营主管** | 运营专员全部权限 + 分成配置复核、超时告警接收、数据修正审批、工单改派 |
| 运营端 | **商务（BD）** | 对接海外平台、平台定级、选定发行平台、维护平台库与平台联系人、录入平台上架结果 |
| 运营端 | **财务** | 审核企业认证资料（可与运营共管）、核对结算单、审核发票、确认打款 |
| 管理端 | **超级管理员** | 账号与角色权限、平台库/首批5家默认平台配置、结算周期、数据同步规则、字典、操作日志 |

## 2. 三端信息架构

> 三端 = **用户端（客户 Web）**、**运营端（运营/商务/财务工作台）**、**管理端（超管配置后台）**。运营端与管理端可同一套后台按角色区分菜单。

### 2.1 用户端（一级菜单固定 3 个）

```
用户端
├── 数据详情                         ← 一级菜单 1
│   ├── 数据总览（总播放量/总收益/在发剧集数/发行平台数，数据截至时间）
│   ├── 剧集数据（按剧集 × 平台 × 日期：播放量、完播率、收益等；趋势图；导出）
│   ├── 平台数据（按平台汇总对比）
│   └── 结算与提款
│       ├── 可结算周期列表 → 发起结算申请
│       ├── 结算单详情（分成明细、保底/超保底拆分）
│       ├── 上传发票 → 提款
│       └── 提款记录
├── 视频存储库                       ← 一级菜单 2
│   ├── 影片列表（状态筛选：草稿/审核中/需修改/已通过/发行中/已下架）
│   ├── 上传影片（影片信息 + 剧集批量上传 + 封面/海报/预告 + 字幕 + 授权书/版权证明）
│   ├── 影片详情
│   │   ├── 剧集列表（逐集审核状态）
│   │   ├── 发行计划（首发：默认首批5家；二轮：手填目标平台）
│   │   ├── 各平台发行状态
│   │   └── 相关工单（审核结果 / 防伪截图）
│   └── 发起发行计划（入口也可在影片列表行操作）
├── 合同申请及列表                   ← 一级菜单 3
│   ├── 合同列表（发行合同/补充协议；状态：申请中/起草中/待签署/已生效/已到期）
│   ├── 发起合同申请（关联影片 + 发行计划 + 分成方案）
│   └── 合同详情（分成条款、保底条款、附件下载、签署记录）
│
└── 配套（非一级菜单：右上角头像/账户中心 + 关键流程中拦截引导）
    ├── 企业绑定与认证（营业执照、法人、对公信息）
    ├── 收款账户（对公账户，需与认证主体一致）
    ├── 授权书 / 版权证明（企业级资质库，上传影片时可复用）
    ├── 工单中心（审核结果工单、防伪截图工单、数据异议工单）——右上角铃铛
    └── 子账号管理（后续）
```

**拦截引导规则**
- 未企业认证：可上传影片、可看数据；**不可发起合同申请、不可提款**（提示去认证）。
- 未上传授权书/版权证明：不可发起发行计划。
- 未绑定收款账户：不可提交提款。

### 2.2 运营端

```
运营端
├── 工作台（待审核剧集数、待配分成、今日数据同步进度/倒计时、超时告警、待处理工单）
├── 客户管理（客户列表、企业认证审核、资质文件审核）
├── 内容审核
│   ├── 发行计划队列（首发 / 二轮 标签）
│   ├── 剧集逐集审核（预览播放、打点批注、通过/驳回+原因模板）
│   └── 分成配置（按平台：保底 / 超保底 / 无保底；主管复核）
├── 发行管理（运营+商务）
│   ├── 平台定级（剧集定级 S/A/B/C【待确认】）
│   ├── 选平台发行（勾选平台、记录对接人、上架时间、上架链接/ID）
│   └── 平台发行状态看板（剧集 × 平台）
├── 平台库（商务维护：平台信息、地区、等级、接口能力、联系人、首批5家标记）
├── 数据同步
│   ├── 同步任务看板（按平台：API 自动 / 手工；今日状态、截止 06:00 倒计时）
│   ├── 手工录入页（按 平台 × 日期 × 剧集 表格录入）
│   ├── Excel 导入（模板下载、校验预览、错误行定位、确认入库）
│   ├── 数据修正（修改已发布数据需填原因，主管审批，留痕）
│   └── 接口调研登记（每个平台的接口情况/对接进度）
├── 工单中心（审核结果工单、防伪截图工单、数据异议工单）
│   └── 防伪截图（水印相机模式：截图/拍摄 → 自动加时间戳水印 → 关联工单）
├── 合同管理（处理客户合同申请、上传合同文本、签署状态）
└── 结算管理（财务）
    ├── 结算单生成/核对
    ├── 发票审核
    └── 打款确认（上传打款凭证）
```

### 2.3 管理端

```
管理端
```

```mermaid
flowchart TD

    C -- 二轮 --> E[客户手动填写目标平台]
    D --> F[提交发行计划]
    E --> F
    F --> G[运营逐集审核]
    G --> H{审核结果}

    I --> J[客户修改后重新提交]
    J --> G
    H -- 通过 --> K[按平台配置分成<br/>保底/超保底/无保底]
    K --> K2[主管复核分成]
    K2 --> L[审核通过工单回传<br/>含分成方案]
    L --> M[运营+商务对接平台]
    M --> N[平台定级]
    N --> O[选平台发行<br/>平台侧上架由线下完成]
    O --> P[录入上架结果<br/>+防伪水印截图工单]
    P --> Q[数据同步<br/>API或每日06:00前手工]

    R --> S[结算周期到期<br/>客户发起结算申请]
    S --> T{企业已认证?}
    T -- 否 --> T1[企业认证] --> T
    T -- 是 --> U[财务核对结算单]
    U --> V[客户上传发票]
    V --> W[财务审核发票并打款]
    W --> X[提款完成]
```

### 3.2 剧集审核与工单回传（泳道）

```mermaid
sequenceDiagram
    participant C as 客户
    participant S as 系统
    participant O as 运营专员
    participant M as 运营主管
    C->>S: 提交发行计划(影片+剧集+目标平台)
    S->>O: 进入审核队列(首发/二轮标签)
    loop 逐集
        O->>S: 单集 通过/驳回(原因模板+时间点批注)
    end
    alt 存在驳回集
        S->>C: 审核工单(驳回集清单+原因)
        C->>S: 替换素材/修改信息 → 重新提交(仅驳回集需复审)
        S->>O: 回到审核队列(标记第N次提交)
    else 全部通过
        O->>S: 按平台配置分成
        S->>M: 分成复核
        M->>S: 复核通过
        S->>C: 审核通过工单(含各平台分成方案)
    end
```

### 3.3 每日数据同步与超时提醒

```mermaid
flowchart TD
    A[每日 00:00 生成当日同步任务<br/>平台×数据日期] --> B{平台接口能力}
    B -- 有API --> C[定时拉取] --> D{成功?}
    D -- 是 --> H[校验入库]
    D -- 否,重试3次失败 --> E[转手工任务+通知运营]
    B -- 无API --> E
    E --> F[运营手工录入/Excel导入]
    F --> G{06:00前完成?}
    G -- 是 --> H
    G -- 否 --> I[超时告警<br/>站内信+邮件/IM 给运营专员与主管<br/>客户端显示'数据更新中,截至T-2']
    I --> F
    H --> J[校验: 环比异常/负数/重复]
    J -- 异常 --> K[标记待复核,主管确认]
    J -- 正常 --> L[发布到客户端<br/>更新'数据截至时间']

```

提醒节奏（默认，可在管理端配置）：**05:00 预警**（未完成任务提醒责任运营）→ **06:00 超时**（升级运营主管，任务标红）→ **每 30 分钟**重复提醒直至完成。

## 4. 状态机

### 4.1 发行计划（影片级）

```mermaid
stateDiagram-v2
    [*] --> 草稿
    草稿 --> 待审核: 客户提交
    待审核 --> 审核中: 运营领取
    审核中 --> 需修改: 存在驳回集
    需修改 --> 待审核: 客户修改后重新提交
    审核中 --> 分成配置中: 全部集通过
    分成配置中 --> 分成待复核: 运营提交
    分成待复核 --> 分成配置中: 主管退回
    分成待复核 --> 审核通过: 主管复核通过(工单回传)
    审核通过 --> 发行对接中: 运营+商务对接平台
    发行对接中 --> 发行中: 至少1个平台已上架
    发行中 --> 已下架: 全部平台下架/到期
    草稿 --> 已撤回: 客户撤回
    待审核 --> 已撤回: 客户撤回(未领取前)
    已下架 --> [*]
    已撤回 --> [*]
```

### 4.2 单集审核状态

`待审核 → 审核中 → 通过 / 驳回`；`驳回 → 已修改待复审 → 审核中`。已通过的集在重提时**不重复审核**（除非客户替换了该集素材）。

### 4.3 平台发行（剧集 × 平台）

```mermaid
stateDiagram-v2
    [*] --> 待对接
    待对接 --> 对接中: 商务发起
    对接中 --> 平台已拒绝: 平台不接
    对接中 --> 待上架: 平台确认+定级
    待上架 --> 已上架: 录入上架链接/ID+防伪截图
    已上架 --> 已下架: 下架/授权到期
    平台已拒绝 --> [*]
    已下架 --> [*]
```

### 4.4 分成配置（剧集 × 平台）

| 模式 | 必填字段 | 说明 |
|---|---|---|
| 保底 | 保底金额、币种、保底期、客户分成比例 | 平台给保底，期内收益不超过保底按保底结 |
| 超保底 | 保底金额、保底内比例、**超出部分**客户分成比例 | 超过保底部分按另一比例分 |
| 无保底 | 客户分成比例 | 纯按收益分成 |

【待确认】保底金额是否对客户可见、保底在多个结算周期内如何摊销/冲抵。

### 4.5 工单

`已创建 → 待客户查看 → 客户已读 → (客户回复/异议 → 处理中 → 已解决) → 已关闭`
工单类型：审核结果、防伪截图、数据异议、结算异议。

### 4.6 每日同步任务

`待同步 → 同步中 → 已完成 → 已发布`；`同步中/待同步 → 已超时(06:00) → 已完成(超时完成，留记录)`；`已发布 → 修正中 → 已发布(新版本)`。

### 4.7 企业认证

`未认证 → 审核中 → 已认证 / 认证驳回 → 审核中`；主体变更 → `变更审核中`（审核期间保留原认证，冻结提款）。

### 4.8 结算单

```mermaid
stateDiagram-v2
    [*] --> 待申请: 结算周期结束,金额生成
    待申请 --> 核对中: 客户发起(需已认证)
    核对中 --> 待申请: 财务退回
    核对中 --> 待开票: 财务确认
    待开票 --> 发票审核中: 客户上传发票
    发票审核中 --> 待开票: 发票不符
    发票审核中 --> 打款中: 审核通过
    打款中 --> 已到账: 上传打款凭证
    已到账 --> [*]
```

## 5. 功能清单与优先级

> MVP 目标：跑通"注册→上传→发行计划→审核工单→分成→选平台→手工数据同步→看数据→结算提款"闭环。

### 5.1 用户端

## 6. 关键页面要点

### 6.1 手工录入/导入页（运营端）
- 顶部：数据日期（默认 T-1）、平台选择、该平台今日任务状态与 **距 06:00 倒计时**。
- 录入表格：行=该平台在发剧集（自动带出），列=指标（播放量、完播率、新增订阅/解锁、收入、币种…，指标字典按平台可配）。支持复制粘贴整块。
- 导入：下载模板（预填剧集ID与平台剧集ID）→ 上传 → 校验预览（必填、类型、负数、环比 ±300% 异常提示、重复）→ 错误行可就地修改 → 确认入库。
- 每次提交记录 操作人、时间、来源（手工/导入/API）、**附原始报表截图/文件**（可直接走水印相机）。

### 6.2 防伪水印截图（水印相机模式）
- 入口：运营端工单内"拍摄/截图取证"，支持上传截图或网页内截屏。
- **服务端**叠加水印（客户端不可伪造）：北京时间时间戳（精确到秒，取服务器时间）、操作人、工单号、平台名、剧集名、图片 SHA-256 短哈希；平铺半透明暗纹 + 角标明文。
- 原图与水印图同时存档，原图仅运营可见；水印图通过工单推送客户。
- 用途：上架证明、平台后台数据证明、下架证明。

### 6.3 发行计划发起（用户端）
- 首发：自动勾选首批5家平台（只读展示平台名单，客户可取消个别平台【待确认是否允许取消】）。
- 二轮：必须手动填写目标平台（从平台库选择，库中没有的可自由填写，提交后由商务补录平台库）；需说明已发行平台以避免冲突。

## 8. 非功能要点
- 视频存储：对象存储 + 分片上传；单文件建议 ≤ 10GB【待确认】；预览用低码率代理文件。
- 安全：素材下载签名 URL + 有效期；客户数据隔离；敏感操作（分成、打款、数据修正）全量日志。
- 时间：所有截止/水印时间统一 UTC+8；海外平台数据日期按平台时区换算后标注。
- 金额：多币种原值+折算人民币，汇率取值规则【待确认】。

## 9. 可优化点（每条：对我方价值 / 对客户价值）

| # | 优化点 | 对我方的价值 | 对客户的价值 |
|---|---|---|---|
| 1 | **上传即自动质检**（分辨率、时长、黑帧、字幕缺失、集数连续性） | 运营审核工时下降，驳回往返减少 | 提交前就发现问题，缩短上线等待 |
| 2 | **驳回原因结构化模板 + 时间点批注** | 审核口径统一，新运营上手快，可统计高频问题 | 一眼看懂哪集哪秒要改，改一次过 |
| 3 | **仅复审驳回集** | 重复审核量大幅减少 | 修改后通过更快 |
| 4 | **分成方案模板+批量套用** | 配置效率高、减少错配风险 | 分成条款一致透明，减少合同扯皮 |
| 5 | **Excel 导入模板预填剧集ID + 环比异常校验** | 06:00 前完成率提升，录错可提前拦截 | 数据更准、更新更及时 |
| 6 | **"数据截至时间"与更新中提示** | 降低客户催问与客服压力 | 清楚数据新鲜度，不误判表现 |
| 7 | **逐平台替换为 API 同步** | 释放每日手工人力，消除超时风险 | 数据更实时，可更早决策二轮发行 |
| 8 | **服务端防伪水印 + 原图哈希存证** | 争议时有可靠证据，降低纠纷与法律风险 | 对上架/数据真实性放心，增强信任 |
| 9 | **平台表现对比 + 二轮发行推荐** | 提升二轮发行转化，增加分成收入 | 用数据选平台，提升收益 |
| 10 | **结算前自动对账、发票信息预填与校验** | 财务核对与退票次数减少 | 开票一次通过，回款更快 |
| 11 | **资质到期提醒（授权书/版权证明）** | 规避授权过期仍在发行的合规风险 | 提前续约，不中断收益 |
| 12 | **子账号分权（上传/数据/财务）** | 对接人清晰，减少账号共用带来的安全问题 | 团队协作方便，权责分离 |
| 13 | **订阅日报/周报邮件** | 提高客户活跃与续约意愿 | 不登录也能掌握表现 |
| 14 | **在线电子签** | 合同周期缩短、归档规范 | 免邮寄，签约更快 |
