# 海外短剧平台版权方合作调研（首发候选 5 家）

调研时间：2026-10-21（Asia/Taipei）｜方法：WebSearch / WebFetch，查官网、合作页、商店页、行业文章
原则：每条结论附来源；查不到写"未找到公开信息"；不确定写"待确认"；不编造数字。

## 0. 平台选择说明
首发候选：ReelShort、DramaBox、ShortMax、FlexTV、GoodShort。这 5 家都是常被提到的头部"封闭片库型"App（要先审核/授权，不能自助发布），依据见 https://www.character.app/blog/where-to-publish-vertical-drama 。本次没有拿到可信的最新收入排名来做替换，所以保留这 5 家。其他平台（如 NetShort、DramaWave）是否更主流，**待确认**。

## 2. 上架/合作要求

### ReelShort
- 没有面向公众的成片上传入口，主要靠委约编剧、自制或合作工作室，外加不定期比赛。来源：https://www.character.app/blog/where-to-publish-vertical-drama
- 第三方文章说投稿通常包括梗概、整季分集大纲、2–3 集样片和主创资历。这是二手信息，**待确认**。来源同上
- 支持多语言：App Store 列出英语外加 21 种语言。来源：https://apps.apple.com/us/app/reelshort-stream-drama-tv/id1636235979
- 版权文件、格式、码率、字幕文件格式：未找到公开信息

### DramaBox
- 官方合作页：持有短剧版权的一方把作品发到 distribution@dramabox.com；剧本改编和字幕翻译走 adaptation@dramabox.com；英文剧制作走 production@dramabox.com。来源：https://www.dramabox.com/business
- 日本站 FAQ（官方）：15–100 集可以上架，集长和集数可以按平台规格商量；流程是先交样片 → 内容确认 → 签约 → 按平台指定格式交付 → 技术检查 → 上线；会有配信手续费或准备费用，单独报价，部分可能从收入中扣除；非独家可以，独家另谈，有独家特典。来源：https://dramabox.jp/creators
- 具体文件格式和版权文件清单：未找到公开信息。第三方建议准备权利链、音乐授权、肖像/声音授权、字幕和干净音轨（来源：https://openmicrodrama.com/guides/publishing-and-monetizing ），**待确认**是否为官方要求

### ShortMax
- 创作者聚合页：独家和非独家作品都收，联系 customerservice1@shortmax.com。来源：https://www.shorttv.live/udrama
- Upload Service 条款（2026-04-16 更新）：
  - 上传方授予非独家、全球的托管和播放许可；
  - 上传方须保证已取得全部权利和许可（含音乐、第三方素材）；
  - 禁止色情、侵权、仇恨、刷量等内容；
  - 有 DMCA 重复侵权封号机制；
  - 视频存储在美国。
  
  来源：https://www.shorttv.live/upload
  注意：这份条款偏 UGC 托管，和商务授权合同是什么关系，**待确认**
- 格式、集数、时长、字幕：未找到公开信息

### FlexTV
- FlexTV Alliance 分三类入口：KOL（可申请）、Developer SDK（Coming Soon）、Content Provider（Coming Soon）。来源：https://a.flextv.cc/
- 商店页写明内容"fully licensed"，提供英、日、中等多语字幕；联系方式 business@flextv.cc（经搜索摘要获得，**待确认**）。来源：https://play.google.com/store/apps/details?id=com.aytech.flextv
- 其他要求：未找到公开信息

### GoodShort
- 出版方、聚合商、内容方想通过 GoodShort 售卖 reels，联系 copyright@goodnovel.com。来源：https://www.goodshort.com/business
- 其他要求：未找到公开信息

### 行业通用（非平台官方）
签约时应逐部核对权利链，并写清地域、渠道、期限、独家性、可否转授权、分账口径、结算周期和违约责任。来源：https://www.gaopenglaw.com/content/details11_4802.html 、https://www.faceproduction.net/article/short-drama-licensing-guide

## 4. 分成模式

| 模式 | 定义 | 平台公开情况 |
|---|---|---|
| 无保底（纯分账） | 按实际收入（常为扣除平台费/投流后的净收入）比例分配 | 各平台的比例均未找到公开信息。有行业文章称新合作中纯分成"generally declined"，常要求预付（https://www.faceproduction.net/article/short-drama-licensing-guide ） |
| 保底（MG） | 先支付最低保证金 | DramaBox 日本站明确写"基本为 MG+分成"（https://dramabox.jp/creators ），金额未公开 |
| 超保底分成 | 保底一般先抵扣分成，累计应分超过保底后才继续支付 | 行业通行做法（https://news.qq.com/rain/a/20260309A07TQ500 ）；VIPO 日中合同范本示例为净收入 1:1、保底可抵扣、按季度结算、每月报告、可审计 5 年（https://www.vipo.or.jp/u/contract-china-3-1-2.pdf ）。这只是范本，不是任何平台的实际条款 |
| 买断/固定采购 | 一次性付费，之后不参与分成 | 行业常见模式（https://www.gaopenglaw.com/content/details11_4802.html ）。界面新闻报道海外平台与制作公司"以承制为主、分成为辅"（https://www.jiemian.com/article/11128785.html ） |

各平台分成比例、保底金额：**均未找到公开信息**，需要在商务谈判中索要。ShortMax 方面，第三方推广站称 CPS 分成 50%，但该站自称非官方，而且针对的是分销推广而不是版权方，所以不采用，**待确认**。

## 6. 手工同步方案（没有接口时）

### 6.1 节奏
- **每日 06:00（UTC+8）前**完成前一自然日数据的录入。
- 统计口径按平台后台时区（多为 UTC 或 PT，**待确认**），并在表中记录所用时区。
- 流程：
  - T 日 00:00–04:30：运营登录各平台后台或打开报表邮件，截图、导出；
  - 04:30–05:30：录入并自检；
  - 05:30–06:00：复核人抽检并锁定。
- 超时未完成：触发告警，在群内通知，记"缺报"。

### 6.2 导出格式
- 主表：**Excel（.xlsx）**，每个平台一个 Sheet，另设"汇总"和"异常"两个 Sheet。
- 同时导出 **CSV（UTF-8 with BOM，逗号分隔，ISO 日期）**供系统入库。
- 文件命名：`shortdrama_daily_{YYYYMMDD}_{platform}_{operator}.csv`
- 截图存证目录：`/evidence/{YYYYMMDD}/{platform}/{drama_id}_{field}_{HHMMSS}.png`

### 6.3 字段清单

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| record_id | string | 是 | 平台+日期+剧ID+语言 拼接，唯一 |

| platform | enum | 是 | ReelShort/DramaBox/ShortMax/FlexTV/GoodShort |

| title_local | string | 是 | 平台上线标题 |
| language | string | 是 | 字幕/配音语种 |
| territory | string | 否 | 国家/地区（平台提供时填写） |
| episodes_online | int | 是 | 已上线集数 |
| views | int | 是 | 播放量（注明口径：播放次数/UV） |
| view_metric_def | string | 是 | 口径说明 |

### 6.4 截图存证（带时间戳水印）
- 截全屏或整页，必须包含：URL 栏、账号名、日期筛选器、数据区。
- 用脚本自动加水印（例如 ImageMagick：`magick in.png -gravity southeast -pointsize 22 -fill 'rgba(255,0,0,0.6)' -annotate +10+10 "平台|剧ID|操作人|$(date '+%F %T %Z')" out.png`）。
- 水印内容：平台、剧目、操作人、截图时间（UTC+8）。
- 生成 SHA-256 写入表格；原图和水印图都保留，原图设为只读并归档。
- 可选：每天把哈希清单发到内部邮件或存入不可改存储，作为第三方时间证明。

### 6.5 校验流程
1. 格式校验：必填项、类型、枚举、record_id 唯一（用脚本或数据验证完成）。
2. 一致性校验：抽查 ≥20% 记录，截图数字与录入值必须一致；新上线剧目全部检查。
3. 合理性校验：
   - 日环比 ±50% 以上标为异常；
   - 累计值不能减少；
   - 收入 > 0 而播放 = 0 标为异常；
   - 已上线集数不超过合同集数。
4. 交叉对账：每月用平台官方结算单对日数据合计，差异 >2% 时发起商务核对（阈值**待确认**，按合同定）。
5. 锁定：复核通过后状态改为"已锁定"；之后修改必须新增修订记录，保留原值、原因和审批人。
6. 审计：截图、CSV 和哈希清单至少保留到合同期满后 5 年（参考 VIPO 范本审计期，可按合同调整）。
