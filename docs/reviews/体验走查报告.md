# 短剧发行平台原型 · 全量产品体验走查报告

- 走查对象：`短剧发行平台原型.html`（源码 `src/`），基准 PRD v0.4；仅走查，未改动原型代码。
- 方法：Playwright / Chromium，1440×900，遍历两端 19 个路由 + 2 个非法路由；对每页内容区全部按钮/链接逐个点击（每次重载页面），记录 URL 变化、DOM 变化、toast、控制台；另跑 40+ 条关键流程脚本（空提交、非法输入、状态流转）。截图在 `walkthrough-shots/`（`NN-路由.png` 为路由全页，`fNN-*.png` 为流程截图）。
- 控制台：全程 **0 条 error / pageerror**。
- 判定口径：P0 = 阻断 MVP 闭环或违反 PRD【已定】项；P1 = 影响主流程体验/缺少 PRD P0 子功能；P2 = 打磨类。

**最关键 10 条**
1. 【2-01】运营端缺「客户管理/企业认证审核」页，`#/o/customers` 白屏；用户端也无“未认证→提交认证→审核中/驳回”流程，认证闭环断。
2. 【1-01】提款向导「上传发票」步不上传也能下一步并提交，确认页伪造“发票_JS-202609.pdf”；且提款与开票顺序与 PRD 4.8（先财务核对→待开票→发票审核）相反。
3. 【3-01】提款金额可输入低于最低提款额（¥5,000）照样进入下一步，未按 PRD 禁止提交；也无多张结算单合并勾选（仅单选一张）。
4. 【2-03】结算单状态机缺失：原型只有“可提款/已打款/周期未结束”，PRD 的 待录入/待复核/退回/未达起提额/待申请/核对中/待开票/发票审核中/打款中/已到账/无需结算 均未体现；运营端无独立“复核”动作与“录入人≠复核人”校验。
5. 【3-02】客户端对账单/分成配置仍有「跨期结转」字段与“结转规则”下拉，违反 v0.4【已定】“不再配置跨期结转、系统不计算”。
6. 【2-02】发行计划状态机（草稿/待审核/审核中/需修改/分成配置中/分成待复核/审核通过/发行对接中/发行中/已撤回）无列表与流转，客户提交后无处跟踪；无撤回。
7. 【3-03】草稿/审核中影片详情页显示“首发5平台·已上架”、有播放与收益数据（全剧共用一份 mock），状态与数据自相矛盾。
8. 【2-05】运营端缺「发行管理」：选平台发行、录入上架链接/ID、剧集×平台状态看板（待对接/对接中/平台已拒绝/待上架/已上架/已下架）全部缺。
9. 【2-06】防伪水印截图只在客户端看结果，运营端无“拍摄/截图取证→服务端加水印→关联工单”入口，P0 功能不可走查。
10. 【5-01】视频存储库、审核台、结算录入等列表全部 `pagination={false}`、无搜索/排序/批量；数百部剧、数千部运营量下无法使用；顶部全局搜索框输入回车无任何响应。

两个新增维度要点：**图形化**——结算/汇率/数据录入以密集表格为主，客户侧缺“发行进度条/状态时间线”、缺缩略图墙内状态角标，提款+开票+合同多个分散向导应合并；**规模化**——0 个页面有分页/服务端搜索/批量操作/导入导出/保存视图，审核台单剧单选、分成配置逐行手填、数据录入仅 4 行剧集，均需重构为批量+筛选+虚拟滚动。
